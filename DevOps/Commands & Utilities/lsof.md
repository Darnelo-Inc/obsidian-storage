**lsof** (List Open Files) — это утилита для просмотра списка открытых файлов и сокетов в системе Linux/Unix.  В Unix-системах "всё есть файл": это и обычные файлы, и каталоги, и устройства, и сетевые соединения.

## Для чего используют lsof?

- Посмотреть, какой процесс использует конкретный файл (например, нельзя размонтировать диск — lsof покажет, кто держит файлы открытыми)
- Найти, какой процесс слушает определённый порт
- Выяснить, какие файлы открыты у определённого пользователя
- Помогает в отладке, администрировании и устранении неполадок

## Примеры использования

- **Посмотреть, кто открыл конкретный файл:**

`lsof /путь/к/файлу`

- **Узнать, какие файлы открыты процессом по PID:**

`lsof -p 1234`

- **Показать, кто держит открытыми файлы в директории:**

`lsof +D /путь/к/директории`

- **Найти, кто слушает конкретный порт (например, 80):**

`lsof -i :80`

- **Все открытые пользователем files:**

`lsof -u имя_пользователя`


## Типичный вывод lsof

COMMAND   PID USER   FD   TYPE DEVICE SIZE/OFF   NODE NAME

nginx   12763 root    6u  IPv4  16341      0t0    TCP *:http (LISTEN)

bash     8621 user    2u   CHR  136,1     0t0      4 /dev/pts/1

- **COMMAND** — имя команды
- **PID** — номер процесса
- **USER** — имя пользователя
- **FD** — номер/описание дескриптора (например, 1u — стандартный вывод в режиме записи)
- **TYPE** — тип файла (REG — обычный файл, DIR — директория, CHR — символьное устройство, IPv4/6 — сетевой сокет и т.д.)
- **NAME** — имя файла или описание сокета
