ls (list) — это основная команда для просмотра содержимого каталогов в Unix/Linux.

### Основные опции ls

- ls -l — подробный (long) список с деталями о каждом файле.
- ls -a — показать все файлы, включая скрытые (начинающиеся с точки).
- ls -lh — подробный список в "читаемом" виде (размеры в КБ, МБ).
- ls -R — рекурсивно, показывать содержимое подкаталогов.
- ls -t — сортировка по времени изменения.
- ls -S — сортировка по размеру.
- ls --color — подсветка цветов для разных типов файлов.

Очень часто используется комбинация:

`ls -lah`
  
## Вывод команды ls -l

Пример вывода:

`-rw-r--r-- 1 user group  4096 Jun  9 17:03  file1.txt`
`drwxr-xr-x 2 user group  4096 Jun  8 20:14  my_folder`
`lrwxrwxrwx 1 user group    10 Jun  7 12:31  link_file -> /etc/passwd`

### Детали:

#### 1. Тип и права
- Первая буква — тип файла:
    - - : обычный файл
    - d : каталог (директория)
    - l : символическая ссылка (symlink)
    - c, b : символьное или блочное устройство
    - s : сокет
    - p : канал (pipe)
- Остальные 9 символов — права доступа.
#### 2. Количество жестких ссылок
- Количество жёстких ссылок на файл или количество подкаталогов и файлов внутри директории (для папок).
#### 3. Владелец
- Имя пользователя — кто владеет файлом.
#### 4. Группа
- Групповая принадлежность файла.

#### 5. Размер
- Размер файла в байтах (в ls -lh: КБ, МБ т.д.)
- Для директорий обычно 4096 байт (размер служебной информации каталога).

#### 6. Дата и время
- Время последнего изменения файла (можно менять формат через параметры).

#### 7. Имя файла
- Имя файла или каталога.
- Для символьных ссылок (l) показано ещё, куда они указывают:  
  link_file -> /etc/passwd
