**strace** — это утилита для отладки и анализа работы программ в Linux/Unix. Она позволяет просматривать системные вызовы и сигналы, которые выполняет процесс.

## Для чего нужна команда strace
- **Анализ работы программы на низком уровне** - показывает, какие операции производит приложение с файлами, сетью, памятью и т. д.
- **Поиск ошибок и зависаний** - можно увидеть, что тормозит процесс: например, ожидает файл, которого нет, или заблокированную операцию.
- **Изучение протекающих процессов** - strace незаменим для понимания того, как работают чужие программы или для отладки собственных.

## Как использовать strace

##### 1. Запустить программу под strace
strace имя_программы параметры

**Пример:**
`strace ls -l /tmp`

strace покажет всё, что делает команда ls -l /tmp на уровне системных вызовов.

##### 2. Подключиться к уже запущенному процессу

`strace -p PID`

Где PID — идентификатор работающего процесса.

## Часто используемые опции

- -o файл — записать вывод в указанный файл `strace -o trace.log ls`
- -e вызов — ограничить список отслеживаемых вызовов `strace -e openat,read,write ls`
- -f — отслеживать дочерние процессы (fork/exec) `strace -f some_program`
- -c — краткая статистика по типам вызовов `strace -c ls`

## Практические примеры

- **Найти, какой файл не может открыть программа:** `strace some_program 2>&1 | grep ENOENT`

(ENOENT = ошибка “файл не найден”)

- **Поймать обращение к сети:** `strace -e network some_program`
