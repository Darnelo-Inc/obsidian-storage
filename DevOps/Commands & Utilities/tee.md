## Описание

tee — команда для чтения из стандартного ввода и одновременной записи в:
- Стандартный вывод (экран)
- Один или несколько файлов

Название происходит от сантехнического T-образного соединителя (тройника), который разделяет поток.

## Синтаксис
команда | tee [опции] файл
## Основные опции
- -a — добавить в конец файла (append), а не перезаписывать
- -i — игнорировать сигналы прерывания

## Примеры использования

### 1. Вывод на экран И сохранение в файл
ls -l | tee output.txt
Покажет список файлов на экране **и** сохранит в output.txt

### 2. Добавление в существующий файл
echo "Новая строка" | tee -a log.txt
### 3. Запись в несколько файлов
echo "test" | tee file1.txt file2.txt file3.txt
### 4. Логирование команд с sudo
echo "some config" | sudo tee /etc/config.conf
Полезно, так как sudo echo > file не работает напрямую

### 5. Сохранение вывода с одновременным просмотром
./script.sh | tee log.txt
Видите вывод скрипта в реальном времени **и** сохраняете в файл

### 6. С цепочкой команд
cat file.txt | grep "error" | tee errors.log | wc -l
Находит ошибки, сохраняет в файл и подсчитывает количество

## Практическое применение
- Логирование — сохранение вывода длительных операций
- Отладка — просмотр промежуточных результатов в pipeline
- Аудит — запись действий с одновременным выполнением
