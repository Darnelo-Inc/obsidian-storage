Docker compose позволяет запускать одновременно несколько контейнеров. Используется декларативный подход.

Docker автоматически создаёт изолированную сеть для взаимодействия поднятых контейнеров. Благодаря DNS возможно взаимодействие между контейнерами, используя имена сервисов. Маст хэв, потому что айпишники динамические, а имена статические.

Пример docker-compose.yaml
```yaml
services:
  app:
    build: ./app
  mongo:
    image: mongo 
```

Образ app собирается из Dockerfile, который лежит в каталоге app
Для mongo берётся образ mongo из репозитория.

Запускаются сервисы через команду `docker-compose up`, остановка и удаление контейнеров через `docker-compose down`

Опция `--build` для команды `docker-compose` позволит пересобрать образы.
