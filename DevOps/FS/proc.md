Версии команд top и ps считывают информацию о состоянии процессов из каталога /proc – псевдофайловой системы, в которой ядро помещает информацию о системе(не только про процессы).

Некоторые файлы каталога /proc, которые содержат информацию о процессах:
- **/proc/$pid/cgroup** — группа управления, которой принадлежит процесс.
- **/proc/$pid/cmdline** — содержит параметры командной строки, переданные на этапе запуска процесса.
- **/proc/$pid/cwd** — символьная ссылка на текущую рабочую директорию процесса.
- **/proc/$pid/environ** — содержит переменные окружения, заданные на этапе запуска процесса.
- **/proc/$pid/exe** — символьная ссылка на исполненный бинарный файл.
- **/proc/$pid/fd** — поддиректория с символьными ссылками на файлы, открытые процессом.
- **/proc/$pid/io** — содержит статистику операций ввода/вывода процесса.
- **/proc/$pid/ns** — подкаталог, содержащий ссылку на пространство имён каждого открытого файла.
- **/proc/$pid/limits** — содержит информацию о лимитах использования ресурсов процессом.
- **/proc/$pid/maps** — содержит информацию об отображённых регионах памяти и правах доступа к ним.
- **/proc/$pid/stack** — содержит трассировку вызовов функций в рамках стека ядра.
- **/proc/$pid/stat** — содержит статистику использования ресурсов процессом.
- **/proc/$pid/task/** — директория с информацией о программных потоках.
