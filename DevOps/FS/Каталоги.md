
| Каталог        | Содержимое                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| /bin           | Команды операционной системы ядра                                                                                                 |
| /boot          | Ядро и файлы для его загрузки                                                                                                     |
| /compat        | Файлы и каталоги в системе FreeBSD, обеспечивающие бинарную<br>совместимость с системой Linux                                     |
| /dev           | Файлы устройств: дисков, принтеров, псевдотерминалов и т.д.                                                                       |
| /etc           | Важные файлы запуска и конфигурации системы                                                                                       |
| /home          | Стандартные домашние каталоги пользователей                                                                                       |
| /lib           | Библиотеки, совместно используемые библиотеки и команды, применяемые<br>в каталогах /bin и /sbin                                  |
| /media         | Точки монтирования файловых систем на съемных носителях                                                                           |
| /mnt           | Временные точки монтирования                                                                                                      |
| /opt           | Программные пакеты необязательных приложений (которые пока не находят<br>широкого применения)                                     |
| /proc          | Информация о всех выполняющихся процессах                                                                                         |
| /root          | Домашний каталог суперпользователя (часто просто /)                                                                               |
| /run           | Точки встречи для выполняемых программ (идентификаторы PID, сокеты и т.д.).                                                       |
| /sbin          | Команды, необходимые для обеспечения минимальной работоспособности<br>системы                                                     |
| /srv           | Поля, зарезервированные для распределения через веб и другие серверы                                                              |
| /sys           | Интерфейсы разных ядер (Linux)                                                                                                    |
| /tmp           | Временные файлы, которые могут удаляться при перезагрузке<br>                                                                     |
| /usr           | Иерархия дополнительных файлов и программ                                                                                         |
| /usr/bin       | Большинство команд и исполняемых файлов<br>                                                                                       |
| /usr/include   | Файлы заголовков, предназначенные для компиляции С-программ<br>                                                                   |
| /usr/lib       | Библиотеки и вспомогательные файлы для стандартных программ<br>                                                                   |
| /usr/local     | Локальные программы (программы, создаваемые или устанавливаемые<br>локальным пользователем); отражает структуру каталога /usr<br> |
| /usr/sbin      | Менее важные команды системного администрированияонем<br>                                                                         |
| /usr/share     | Элементы, общие для различных систем<br>                                                                                          |
| /usr/share/man | Страницы интерактивной документации<br>                                                                                           |
| /usr/src       | Исходные коды нелокальных программных пакетов (не находит широкого<br>применения)<br>                                             |
| /usr/tmp       | Дополнительный каталог для временных файлов, которые могут сохраняться<br>при перезагрузке                                        |
| /var           | Системные данные и конфигурационные файлы<br>                                                                                     |
| /var/adm       | Разное: журнальные файлы, записи об инсталляции системы, административные компоненты<br>                                          |
| /var/log       | Системные журнальные файлы<br>                                                                                                    |
| /var/run       | Те же функции, что и в каталоге /run, а также символические ссылки<br>                                                            |
| /var/spool     | Буферные каталоги для принтеров, электронной почты и т.д.<br>                                                                     |
| /var/tmp       | Каталог для временного хранения файлов (после перезагрузки файлы не<br>исчезают)                                                  |
