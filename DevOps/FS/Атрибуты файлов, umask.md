В Linux и других UNIX-подобных системах у каждого файла и каталога есть **биты режима** (права доступа), которые определяют, кто и что может делать с этим объектом.

Типичные права записываются как:  
rwxrwxrwx (по три буквы для **владельца**, **группы** и **остальных**)

Каждый бит можно также записать в виде октального числа:
- r = 4
- w = 2
- x = 1  

Пример: 755 = rwxr-xr-x

| Биты | Значение | Описание            |
| ---- | -------- | ------------------- |
| ---  | 0        | нет прав            |
| --x  | 1        | только выполнение   |
| -w-  | 2        | только запись       |
| -wx  | 3        | запись и выполнение |
| r--  | 4        | только чтение       |
| r-x  | 5        | чтение и выполнение |
| rw-  | 6        | чтение и запись     |
| rwx  | 7        | все права           |

### Специальные биты: setuid, setgid, sticky

#### 1. **setuid** (set user ID)

- **Бит:** 4000 (четвёртая цифра впереди)
- **Действие:** Если у файла с этим битом разрешение на исполнение, запущенный процесс получает **права владельца** файла, а не пользователя, который его запускает.
- **Пример:** файл /usr/bin/passwd — позволяет обычному пользователю менять только свой пароль, а в процессе получает права root.

`chmod u+s ./my_program`

#### 2. **setgid** (set group ID)

- **Бит:** 2000 (вторая цифра впереди)
- **Для файлов:** Процесс при запуске получает права **группы файла**.
- **Для каталогов:** Все создаваемые в каталоге файлы и папки будут наследовать группу этого каталога.
- **Пример:** общий рабочий каталог, где все файлы должны принадлежать одной группе.

`chmod g+s ./my_program`
`chmod g+s ./shared_folder`

#### 3. **Sticky bit** (липкий бит)

- **Бит:** 1000 (первая цифра впереди)
- **Применимо только к каталогам** (обычно /tmp).
- **Значение:** В каталоге можно удалять/перемещать файлы только если ты владелец файла, владелец каталога или root.
- **Пример:** /tmp - все могут создавать файлы, но удалять своё.

`chmod +t ./public_folder`


### Как выглядят права с этими битами

| Побитовые права | Числовое значение | setuid | setgid | sticky |
| --------------- | ----------------- | ------ | ------ | ------ |
| -rwsr-xr-x      | 4755              | да     | нет    | нет    |
| -rwxr-sr-x      | 2755              | нет    | да     | нет    |
| drwxrwxrwt      | 1777              | нет    | нет    | да     |

### Как выставлять

- `chmod 4755 file` — setuid + обычные права 755
-  `chmod 2755 file` — setgid + 755
- `chmod 1755 dir` — sticky + 755

Или в символьной форме:
- `chmod u+s file` — setuid
- `chmod g+s file/dir` — setgid
- `chmod +t dir` — sticky

### umask

umask (user file-creation **mask**) — это специальная настройка в UNIX-подобных системах, которая определяет **базовые права доступа** для новых файлов и директорий, создаваемых пользователем или программами.  

**umask** задаёт какие права **будут ОТНЯТЫ** от прав по умолчанию.

### Права по умолчанию:

- Для новых **файлов** — 666 (rw-rw-rw-)  
- Для новых **директорий** — 777 (rwxrwxrwx)  


### Как посмотреть текущий umask?

umask

Выведет, например, 0022.

umask 022 — **стандартная маска для большинства Linux-систем**. 
Она позволяет всем видеть файлы и заходить в директории, но только самому владельцу разрешает изменять/записывать их.

## Как изменить umask?

В любой сессии (или в скриптах) можно изменить umask:
umask 0002   # Разрешить запись для своей группы
umask 0077   # Только владелец, запретить всё группе и остальным
umask 0027   # Разрешить группe только чтение/исполнение

Маску можно писать и в символьном виде:
umask u=rwx,g=rx,o=
