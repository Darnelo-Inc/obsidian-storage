**ps** - команда, позволяющая узнать информацию о процессах.

Ключи:
- a – вывести все процессы
- u – фильтр по имени или uid пользователя, сопоставляет идентификаторы процессов с именами пользователей (замедляет выполнение)
- x – вывести даже отсоединённые от управляющего терминала процесса
- l – длинный формат вывода
- w – больше столбцов
- ww – снятие ограничения на ширину столбцов

Столбцы вывода:
- USER – имя владельца процесса
- PID – идентификатор владельца
- %CPU – доля времени центрального процессора в процентах, выделенная процессу
- %MEM – процент физической памяти (RAM), который занимает процесс.
- VSZ – общий объём виртуальной памяти, выделенной процессу
- RSS – объём оперативной памяти (RAM), реально занятой процессом в текущий момент
- TTY – идентификатор управляющего терминала
- STAT – текущий статус процесса:
	- R – выполняется
	- D – ожидает записи на диск
	- S – не активен (< 20s)
	- T – приостановлен
	- Z – зомби
	Дополнительные флаги:
	- W – процесс выгружен на диск
	- < – процесс имеет повышенный приоритет
	- N – процесс имеет пониженный приоритет
	- L – некоторые страницы блокированы в ядре
	- s – процесс является лидером сеанса
- TIME – количество времени центрального процесса, затраченного на выполнение процесса
- COMMAND – имя и аргументы команды
- PPID – идентификатор родительского процесса
- NI – фактор уступчивости
- WCHAN – ресурс, которого ожидает процесс

**top** – команда позволяет сделать снимок состояния системы

Во время работы можно управлять выводом:
- q — выход из top  
- h — справка по командам  
- P — сортировать по загрузке CPU  
- M — сортировать по объёму памяти  
- T — сортировать по времени  
- k — завершить процесс (после нажатия, введите PID и сигнал, по умолчанию SIGTERM)  
- r — изменить значение nice для процесса  
- / — поиск по имени процесса  
- 1 — показать загрузку по каждому ядру CPU

Фактор уступчивости – число, по которому ядро определяет свою политику в отношении процессов, конкурирующих за право доступа к центральному процессору. Команда **nice** определяет только приоритет использования ЦП, для управления приоритетами ввода-вывода используется команда **ionice**. Чем выше фактор уступчивости, тем ниже приоритет процесса и наоборот.
Диапазон фактора уступчивости лежит в промежутке от -20 до +19 в Linux, в системах FreeBSD – от -20 до +20.
Дочерний процесс наследует фактор уступчивости родителя. Владелец процесса может только повысить фактор уступчивости. Рут может всё.

Команда **nice** позволяет установить фактор уступчивости при создании процесса, команда **renice** изменить его во время выполнения процесса.

``` bash
$ /usr/bin/nice -n 5 ~/bin/longtask // Понижает приоритетт на 5
$ sudo renice -5 8829      // Задаём фактор уступчивости равным -5
$ sudo renice 5 -u boggs   // Задаём фактор уступчивости равным 5 для всех процессов пользователя boggs
```
