Подключить можно через username/password или username/ssh-key(предпочтительнее)

1. Условно имеем три клиента в амазоне и их ssh-ключи на мастере.
2. На мастере в каталоге `ansible` создадим текстовый файл `hosts.txt`(или inventory, или hostfile), который будет содержать информацию о серверах, к которым может подключиться, и способе подключения.
```txt
[staging_servers]
linuxX    ansible_host=172.31.8.69    ansible_user=ec2-user    ansible_ssh_private_key_file=/home/ec2-user/.ssh/california-key1.pem
```
3. Если подключиться впервые, то сервер попросит fingerprint. Подключаемся командой `ansible -i hosts.txt all -m ping`. Параметр `-i` указывает на файл инвентаря, `all` указывает на целевую группу(в данном случае все хосты из `hosts.txt`), `-m ping` указывает на использование модуля `ping`
4. Что происходит на практике
	4.1. Ansible подключается к каждому хосту из hosts.txt по SSH (по умолчанию).
	4.2. На хост временно копируется и выполняется небольшой Python‑скрипт (часть модуля ping).
	4.3. Хост возвращает ответ pong, если:
	   - подключение успешно;
	   - на хосте есть Python;
	   - нет блокировок (фаервол, права и т. п.).
	4.4. Пример вывода
	- SUCCESS + pong — хост доступен и готов к управлению Ansible.
	- UNREACHABLE — не удалось подключиться (проблемы с сетью, SSH, аутентификацией и т. п.).
``` sh
host1 | SUCCESS => {
    "changed": false,
    "ping": "pong"
}

host2 | UNREACHABLE! => {
    "msg": "Failed to connect to the host via SSH..."
}
```

5. Расширим файл `hosts.txt`
```txt
...
[prod_servers]
linux1    ansible_host=172.31.27.16    ansible_user=ec2-user    ansible_ssh_private_key_file=/home/ec2-user/.ssh/california-key2.pem
linux2    ansible_host=172.31.19.188    ansible_user=ec2-user    ansible_ssh_private_key_file=/home/ec2-user/.ssh/california-key2.pem
```

6. При первом подключении сервер просит подтвердить fingerprint. Можем от этого избавиться, а также прописать путь по умолчанию для файла `inventory`. Для этого создадим файл  `ansible.cfg`:
```cfg
[defaults]
host_key_checking = false
inventory = ./hosts.txt
```

7. Теперь команда пинга `ansible all -m ping` вернёт три пинга от всех хостов группы.
