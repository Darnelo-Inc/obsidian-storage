**POD**

POD - point of deploy. Это самый маленький элемент в мире k8s. Pod состоит из одного или нескольких контейнеров. Для каждого pod-а выделяются ресурсы – место на жестком диске(тома), pod получает ip-адрес. Таким образом, все контейнеры имеют один ip.
Лучше создавать один контейнер на pod.

**Кластер**

Кластер состоит из нод, каждая нода – это сервер. Нагрузка распределяется по нодам. Ноды могут быть физические и виртуальные. На каждой ноде запускаюты поды.
У каждой ноды есть роль. В кластере выбирается главная нода(master node), которая управляет остальными, рабочими нодами(worker node). Нагрузка распределяется между рабочими нодами, в то время как главная нода только контролирует рабочие ноды. Можно создавать резервную мастер ноду.
