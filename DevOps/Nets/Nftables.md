**nf_tables** (nftables) — новый фреймворк для фильтрации пакетов в Linux, замена iptables/ip6tables/arptables/ebtables.
  

## Отличия от iptables:

| iptables                                                  | nftables                            |
| --------------------------------------------------------- | ----------------------------------- |
| Множество утилит (iptables, ip6tables, arptables)         | **Одна утилита** nft                |
| Отдельные таблицы для IPv4/IPv6                           | **Unified** — одна таблица для всех |
| Много дублирующих правил                                  | **Оптимизация** — меньше правил     |
| Медленное обновление (каждое правило — отдельный syscall) | **Batch операции** — быстрее        |
| Сложный синтаксис                                         | **Понятный синтаксис**              |
| Нет переменных/множеств                                   | **Sets, maps, переменные**          |


**Chain** — контейнер для **правил** (rules), которые обрабатывают пакеты в определенной точке.
Аналог цепочек в iptables (INPUT, OUTPUT, FORWARD...).

  
#### Два типа цепочек:

##### 1. **Base chains** (базовые)
Привязаны к **netfilter hooks** — точкам перехвата пакетов в ядре.

##### 2. **Regular chains** (обычные)
Вспомогательные цепочки для переходов (как функции/процедуры).
