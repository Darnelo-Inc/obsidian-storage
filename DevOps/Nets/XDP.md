**XDP, eXpress Data Path** –  сетевая компонента, куда в первую очередь попадают пакеты, пришедшие из сети на хост.

XDP перехватывает пакеты на уровне драйвера сетевой карты, позволяет дропнуть пакет / переправить на другой интерфейс / пропустить дальше. Позволяет фильтровать ddos

**Самый ранний** уровень обработки — **до выделения sk_buff** (структуры пакета ядра).
Работает прямо в **драйвере сетевой карты** или в generic режиме сразу после.


``` c
// eBPF программа на XDP

int xdp_filter(struct xdp_md *ctx) {
    // Доступ к сырым данным пакета
    void *data = (void *)(long)ctx->data;
    void *data_end = (void *)(long)ctx->data_end;
    struct ethhdr *eth = data;

    if (eth + 1 > data_end)
        return XDP_DROP;

    // Быстрая фильтрация
    if (eth->h_proto == bpf_htons(ETH_P_IP)) {
        // Обработать IP пакет
    }

    return XDP_PASS; // или XDP_DROP, XDP_TX, XDP_REDIRECT
}
```
### Действия XDP:

- **XDP_DROP** — отбросить пакет (DDoS защита)
- **XDP_PASS** — передать дальше в ядро
- **XDP_TX** — отправить обратно через тот же интерфейс
- **XDP_REDIRECT** — перенаправить на другой интерфейс
- **XDP_ABORTED** — ошибка

  

### Преимущества:

- ⚡ **Сверхбыстро** — до создания sk_buff
- 🚫 **DDoS защита** — отбрасывать пакеты за наносекунды
- 🔀 **Load balancing** — распределение нагрузки

### Пример использования:

Загрузить XDP программу

`ip link set dev eth0 xdp obj xdp_prog.o sec xdp`
  

Посмотреть статистику

`ip link show dev eth0`
